# PixMo_DINO
This is my current workflow to extract a batch from the dataset (extract_from_tars.py) and create a manifest JSONL file, batch running on filtering pipeline and creating the list of filtered noun chunks for each caption (batch_run_pixmo.py), then creating the .tar folders that keep text and image boxes for each text-image pairing in pixmo caption.
Necessary cmd prompts are explained at the beginning of each file to be run.
